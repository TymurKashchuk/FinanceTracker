# FinanceTracker

FinanceTracker — сучасний десктопний застосунок для обліку особистих фінансів, розроблений на базі WPF (.NET 8) та SQLite. Застосунок надає інструменти для контролю доходів і витрат, детальної аналітики фінансових потоків, планування бюджету та управління кількома рахунками.

---

## Основні можливості

- **Панель керування (Dashboard):**
  - Загальний баланс усіх рахунків у реальному часі.
  - Ключові фінансові показники періоду: сумарні доходи, витрати, чисті заощадження та відсоток заощаджень.
  - Стрічка останніх транзакцій та перелік рахунків із кольоровою індикацією балансів.

- **Гнучка система періодів:**
  - Швидкі пресети фільтрації: «Сьогодні», «Тиждень», «Місяць», «Весь час».
  - Власний діапазон дат («Свій період») з автоматичним контролем коректності меж (`Дата з` <= `Дата по`).
  - Інформаційний бейдж активного діапазону.

- **Швидке додавання операцій (Quick Add):**
  - Зручна форма з можливістю згортання.
  - Швидкі кнопки вибору дат («Сьогодні», «Вчора»).
  - Автоматична фільтрація категорій залежно від обраного типу операції (дохід / витрата).
  - Миттєва валідація введених даних із підсвічуванням статусів (успіх / помилка).

- **Журнал транзакцій:**
  - Повна таблиця операцій із можливістю пошуку за описом або категорією.
  - Фільтрація за конкретним рахунком або типом (усі, тільки витрати, тільки доходи).
  - Безпечне видалення випадкових записів через контекстне меню або кнопку в рядку з діалогом підтвердження.
  - Експорт відфільтрованих транзакцій у файл CSV.

- **Аналітика та бюджети:**
  - Кругова діаграма розподілу витрат за категоріями на базі LiveCharts.
  - Рейтинг топ-категорій витрат із сумами та відсотковим співвідношенням.
  - Контроль місячних бюджетів за категоріями з відстеженням фактичних витрат.

- **Сучасний інтерфейс користувача:**
  - Лаконічний корпоративний стиль без зайвих візуальних шумів.
  - Чіткі векторні SVG-іконки (StreamGeometry).
  - Повністю клікабельні поля вибору дат з локалізацією (`uk-UA`).

## Технологічний стек

- **Платформа:** .NET 8 (WPF — Windows Presentation Foundation)
- **Мова програмування:** C# 12
- **Архітектурний патерн:** MVVM (Model-View-ViewModel) з модульною декомпозицією компонентів
- **База даних та ORM:** SQLite, Entity Framework Core 8.0
- **Візуалізація графіків:** LiveCharts.Wpf

## Архітектура та структура проєкту

```text
FinanceTracker/
├── FinanceTracker.sln
├── finances.db                     # База даних SQLite
└── FinanceTracker.wpf/
    ├── Converter/                  # XAML конвертери значень і кольорів
    ├── Data/                       # EF Core DbContext та конфігурація сутностей
    ├── Helpers/                    # Утиліти розрахунку часових діапазонів (DateTimeHelper)
    ├── Models/                     # Моделі даних, DTO та Enums
    ├── Services/                   # Бізнес-сервіси (FinanceService, TransactionValidator)
    ├── ViewModels/                 # Модульні partial-класи ViewModel (Navigation, Period, QuickAdd, Transactions, Analytics)
    ├── Views/                      # Компоненти інтерфейсу (SidebarView, TopBarView, QuickAddView, HomeView, TransactionsView, SummaryView)
    ├── App.xaml                    # Глобальні стилі, колірна палітра, векторні SVG-іконки
    └── MainWindow.xaml             # Кореневий контейнер застосунку
```

## Встановлення та запуск

### Кроки для запуску

1. Клонувати репозиторій:
   ```bash
   git clone https://github.com/TymurKashchuk/FinanceTracker.git
   cd FinanceTracker
   ```

2. Відновити залежності та зібрати проєкт:
   ```bash
   dotnet restore
   dotnet build
   ```

3. Запустити застосунок:
   ```bash
   dotnet run --project FinanceTracker.wpf
   ```

База даних `finances.db` ініціалізується автоматично під час першого запуску застосунку разом із базовими рахунками та категоріями за замовчуванням.
